# 🎵 Music Folder - Hướng dẫn sử dụng

## 📁 Cấu trúc thư mục
Đặt file MP3 vào thư mục này với các tên sau:

### 📚 Study Music (Danh sách học tập)
- `background1.mp3` - Background Music 1
- `background2.mp3` - Background Music 2
- `background3.mp3` - Background Music 3

### 🌙 Ambient Music (Nhạc thư giãn)
- `ambient1.mp3` - Chill Ambient
- `ambient2.mp3` - Deep Focus

### 🎯 Focus Music (Nhạc tập trung)
- `focus1.mp3` - Study Focus
- `focus2.mp3` - Concentration
- `focus3.mp3` - Deep Work

## 🔧 Hướng dẫn setup:

1. **Download file MP3 từ internet** (miễn phí từ các trang như freesound.org, pixabay.com)
2. **Đổi tên file** theo danh sách trên
3. **Copy vào thư mục này**
4. **Reload trang web** để test

## ✅ Ví dụ cấu trúc hoàn chỉnh:
```
music/
├── README.md (file này)
├── background1.mp3
├── background2.mp3  
├── background3.mp3
├── ambient1.mp3
├── ambient2.mp3
├── focus1.mp3
├── focus2.mp3
└── focus3.mp3
```

## 🎶 Lưu ý:
- File phải là định dạng **MP3**
- Kích thước file không quá lớn (< 10MB/file)
- Tên file **phân biệt hoa/thường**
- Không có dấu cách trong tên file

## 🚀 Sau khi setup xong:
1. Mở quiz app
2. Click vào music player ở góc trái trên
3. Chọn playlist từ dropdown
4. Nhạc sẽ tự động chuyển bài khi hết!
